# Security Policy

If you discover a security vulnerability in CXploit itself (not a
module's intended exploit behavior, but a flaw in the framework code),
please report it privately rather than opening a public issue.

Contact: [Report a vulnerability via GitHub Advisory](https://github.com/ravichandran3/cxploit-framework/security/advisories/new)

Please do not test CXploit's exploitation modules against systems you
do not own or have explicit written authorization to test.
