What is CxPloit-Framework?

CxPloit-Framework is a Python-based security testing framework that provides a structured environment for developing, organizing, and executing exploit code. It separates concerns into five distinct layers — from user interface down to persistent storage — and uses a dynamic module loader to discover and register exploit, payload, encoder, auxiliary, and post-exploitation modules at runtime.

Unlike standalone exploit scripts, CxPloit provides shared infrastructure: payload generation, session management, encoder chaining, handler/listener setup, and workspace isolation — so every module benefits from the same capabilities without reimplementing them.

Key Features
Modular Plugin System
Drop-in modules auto-discovered from disk. Each module implements a standard interface with options(), check(), run().
Staged Payload Delivery
Stager (small bootloader) + Stage (full payload) pattern for reliable delivery across restricted networks and character-limited injection points.
Encoder Chaining
Stack multiple encoders (XOR, Shikata Ga Nai, character exclusion) to produce polymorphic shellcode that evades signature-based AV/EDR.
Session Routing & Pivoting
Active sessions double as tunnel endpoints. Route commands through compromised hosts to reach internal network segments.
Workspace Isolation
Separate workspaces for different engagements. Hosts, credentials, loot, and config are fully isolated per-workspace.
Event-Driven Architecture
Pub/sub event bus connects all layers. UI updates, module triggers, and session events flow through a single unified channel.

Architecture
System Architecture
Five-layer decoupled architecture. Each layer communicates only through the Event Bus and Data Store — no direct cross-layer coupling.
Layer Stack (Top → Bottom)
L1
User Interface Layer
CLI (REPL shell), Web GUI (Flask dashboard), API/SDK (REST + Python bindings). All interfaces connect to the same Core Engine via a unified controller.
cmdloopFlaskREST
L2
Core Engine Layer
The orchestrator: Module Loader, Exploit Dispatcher, Session Manager, Payload Builder, Handler System, Event Bus, Encoder Chain, Data Store, Report Engine. This is the heart of the framework.
engine.pymodule_loadersession_mgrpayload
L3
Module Ecosystem Layer
Four module types: Exploits (RCE, LPE, DoS), Payloads (reverse, bind, meterpreter), Encoders (XOR, SGN, charset), Auxiliary (scanners, fuzzers, recon). All implement the ModuleBase interface.
exploitspayloadsencodersauxiliary
L4
Post-Exploitation Layer
Privilege escalation, persistence mechanisms, network pivoting (SOCKS/port forward), loot & credential collection. Operates through active sessions.
privescpersistpivotloot
L5
Infrastructure & Storage Layer
Database (SQLite/PostgreSQL), networking sockets (TCP/UDP/HTTP/SSL), file I/O, logging, and configuration management.
sqlitesocketssl
Cross-Layer Communication
Layers never import each other directly. All communication flows through two mechanisms:
  • Event Bus — publish/subscribe pattern. Any layer can emit events (exploit.launched, session.opened, module.loaded) and any layer can subscribe.
  • Data Store — centralized key-value store with workspace-scoped namespaces. Modules read/write options, the CLI reads state, the DB layer persists.

Core Engine engine.py
Core Engine
The central orchestrator that wires all components together and drives the exploit lifecycle.
Class: CxPloitEngine
PYTHON — core/engine.py
class CxPloitEngine: """Central orchestrator for the CxPloit framework.""" def __init__(self, config_path="config.yml"): # Initialize all core subsystems self.module_loader = ModuleLoader() self.session_mgr = SessionManager() self.payload_builder = PayloadBuilder() self.handler_sys = HandlerSystem() self.event_bus = EventBus() self.datastore = DataStore() self.encoder_chain = EncoderChain() self.report_engine = ReportEngine() self.active_module = None self.running = False def initialize(self): """Boot sequence: load config, init DB, discover modules.""" self.datastore.connect() self.module_loader.discover("modules/") self.handler_sys.start_listeners() self.event_bus.emit("engine.ready") def use_module(self, module_path: str): """Load a module by its path (e.g. 'exploit/linux/http/cve_xxx').""" self.active_module = self.module_loader.load(module_path) self.event_bus.emit("module.selected", module_path) def execute_exploit(self): """Run the full exploit pipeline: check → exploit → handle.""" if self.active_module.check(): payload = self.payload_builder.build(self.active_module) self.encoder_chain.apply(payload) result = self.active_module.run(payload) session = self.handler_sys.accept() self.session_mgr.register(session) self.event_bus.emit("session.opened", session) def shutdown(self): """Graceful teardown: close sessions, stop listeners, save state.""" self.session_mgr.close_all() self.handler_sys.stop_all() self.datastore.save() self.event_bus.emit("engine.shutdown")

class ModuleLoader: """Discovers and loads modules from the modules/ directory tree.""" def __init__(self): self.registry = ModuleRegistry() self.module_paths = [] # List of discovered .py files self.loaded = {} # path → module_class mapping def discover(self, base_dir: str = "modules/"): """Walk the modules/ tree and catalog all Python files.""" for root, dirs, files in os.walk(base_dir): for f in files: if f.endswith(".py") and not f.startswith("_"): self.module_paths.append( os.path.join(root, f) ) def load(self, module_path: str) -> ModuleBase: """Import a module file and return its class instance.""" spec = importlib.util.spec_from_file_location( module_path, self._resolve(module_path) ) mod = importlib.util.module_from_spec(spec) spec.loader.exec_module(mod) cls = self._find_module_class(mod) instance = cls() self.loaded[module_path] = instance return instance def _find_module_class(self, mod) -> type: """Find the class in a module that inherits from ModuleBase.""" for name, obj in inspect.getmembers(mod, inspect.isclass): if issubclass(obj, ModuleBase) and obj is not ModuleBase: return obj def load_all(self): """Load every discovered module into the registry.""" for path in self.module_paths: try: instance = self.load(path) self.registry.register(instance) except Exception as e: logger.warning(f"Failed to load {path}: {e}")

Pivoting via Sessions
When route_through(session_id, subnet) is called, all traffic destined for that subnet is tunneled through the specified session's connection. This enables lateral movement into internal networks without direct connectivity.
Core payload_builder.py
Payload Builder
Assembles payloads from stager + stage components, applies encoder chains, and outputs in multiple formats.
Class: PayloadBuilder
PYTHON — core/payload_builder.py
class PayloadBuilder: """Builds payloads by assembling stager + stage + encoder chain.""" def build(self, module: ModuleBase) -> bytes: """Full build pipeline: select payload → assemble → encode → format.""" payload_mod = self.resolve_payload(module) raw = payload_mod.generate() if payload_mod.staged: stager = payload_mod.stager() stage = payload_mod.stage() raw = stager + stage encoded = self.encoder_chain.apply(raw, module.options) return self.format_output(encoded, module.options) def resolve_payload(self, module) -> PayloadBase: """Resolve the payload module from the module's PAYLOAD option.""" payload_path = module.options["PAYLOAD"] return self.registry.get(payload_path) def format_output(self, data: bytes, opts: dict) -> bytes: """Transform raw shellcode into the requested output format.""" fmt = opts.get("FORMAT", "raw") if fmt == "raw": return data elif fmt == "exe": return self._wrap_pe(data) elif fmt == "elf": return self._wrap_elf(data) elif fmt == "python": return self._wrap_python(data) elif fmt == "c": return self._wrap_c(data)

Core handler_system.py
Handler System
Network listeners that catch payload callbacks and establish sessions.
Handler Types
ReverseTCPHandler
Listens on LHOST:LPORT. Target connects back. Bypasses inbound firewalls.
def listen(self, lhost, lport): sock = socket.socket() sock.bind((lhost, lport)) sock.listen(5) conn, addr = sock.accept() return Session(conn, addr)
BindTCPHandler
Connects to target's listening port. Requires target to open a port. Works when egress is filtered.
def connect(self, rhost, rport): sock = socket.socket() sock.connect((rhost, rport)) return Session(sock, (rhost, rport))
ReverseHTTPHandler
Payload callbacks over HTTP/HTTPS. Polls for commands. Bypasses deep packet inspection.
MultiHandler
Listens on one port, dispatches to different payload handlers based on the connecting payload type.

class EventBus: """Simple pub/sub event bus for decoupled communication.""" _subscribers: dict[str, list[Callable]] = defaultdict(list) def subscribe(self, event: str, handler: Callable): """Register a handler for an event name.""" self._subscribers[event].append(handler) def emit(self, event: str, *args, **kwargs): """Publish an event; all subscribers are called.""" for handler in self._subscribers.get(event, []): handler(*args, **kwargs) def unsubscribe(self, event: str, handler: Callable): """Remove a handler from an event.""" self._subscribers[event].remove(handler)
